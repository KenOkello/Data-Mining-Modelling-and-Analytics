
# Data Mining, Modelling and Analytics 1

This repository contains practical assignments undertaken as part of the **MSc Data Science and Analytics programme at Uganda Christian University (UCU)**. The projects demonstrate the application of machine learning techniques to real-world classification and regression problems using Python.

## Project 1: Bank Marketing Classification
Predicts whether a customer will subscribe to a bank term deposit using Logistic Regression, Random Forest, and Gradient Boosting. Model performance is evaluated using cross-validation, precision, recall, F1-score, and ROC-AUC.

## Project 2: Concrete Compressive Strength Prediction
Predicts concrete compressive strength based on mixture composition and curing age. Linear Regression and Random Forest Regression are compared using MAE, RMSE, R², and residual analysis.

## Tools and Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, and Jupyter Notebook.

## How to Run
1. Download or clone the repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Open the Jupyter notebooks in VS Code or Jupyter.
4. Run all cells sequentially.
